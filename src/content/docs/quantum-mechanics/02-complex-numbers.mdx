## 1. The Geometry of Imaginary Numbers

Calling complex numbers "imaginary" is an unfortunate historical accident. Positive and negative signs encode **one-dimensional orientation** (+1 is forward, -1 is reverse). Multiplying by -1 is a $180^\circ$ flip along a single line.

Multiplying by $i$ represents a **$90^\circ$ counter-clockwise rotation** in a two-dimensional number plane:

```math
i \times 1 = i \quad (90^\circ)
```
```math
i \times i = i^2 = -1 \quad (180^\circ)
```

## 2. Euler's Formula and Polar Form

Any complex number $z = x + iy$ can be decomposed into an absolute magnitude (radius $r$) and a phase angle ($\theta$):

```math
z = r e^{i\theta} = r (\cos\theta + i\sin\theta)
```

Where:
* **Magnitude**: $r = |z| = \sqrt{x^2 + y^2}$
* **Phase**: $\theta = \arctan\left(\frac{y}{x}\right)$

In quantum mechanics, a wavefunction's state is an element of a complex Hilbert space:

```math
\Psi(x, t) = \psi(x) e^{-i E t / \hbar}
```

The complex phase factor $e^{-iEt/\hbar}$ drives interference phenomena while preserving probability normalization:

```math
P(x) = |\Psi(x, t)|^2 = \Psi^* \Psi = |\psi(x)|^2
```

  Convert the complex number $z = 1 + i\sqrt{3}$ into exponential polar form $r e^{i\theta}$.

  <div slot="solution">
    1. Calculate magnitude:
    ```math
    r = \sqrt{1^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = 2
    ```
    2. Calculate phase angle:
    ```math
    \theta = \arctan\left(\frac{\sqrt{3}}{1}\right) = \frac{\pi}{3} \quad (60^\circ)
    ```
    Therefore:
    ```math
    z = 2 e^{i\pi/3}
    ```
