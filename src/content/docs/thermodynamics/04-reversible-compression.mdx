## 1. Reversible vs. Irreversible Work

Compression work on a gas is defined by the external opposing pressure $P_{\text{ext}}$:

```math
w = -\int_{V_1}^{V_2} P_{\text{ext}} \, dV
```

* **Single-Stage Irreversible Compression**: A large external weight is placed instantly on the piston ($P_{\text{ext}} = P_2$). The work done on the gas is:
  ```math
  w_{\text{irrev}} = -P_2 (V_2 - V_1) = P_2 (V_1 - V_2)
  ```
* **Reversible Compression**: External pressure is adjusted infinitesimally ($P_{\text{ext}} = P_{\text{gas}} \pm dP$) at every step:
  ```math
  w_{\text{rev}} = -\int_{V_1}^{V_2} \frac{n R T}{V} \, dV = n R T \ln\left(\frac{V_1}{V_2}\right)
  ```

Because $P_2 (V_1 - V_2) > nRT \ln(V_1 / V_2)$ for any non-zero compression, **reversible compression always demands the minimum possible work** to reach the final state.
