## 1. The Core Dilemma: Hidden Internal Energy

We cannot directly place a sensor inside a gas to count the kinetic and potential energies of $10^{23}$ molecules. Instead, thermodynamics relies on an ingenious dual system:

* **State Functions ($U, H, S, G, T, P, V$)**: Depend solely on the current equilibrium state of the system, independent of how it got there.
* **Path Functions ($w, q$)**: Depend entirely on the specific trajectory taken through state space.

```math
\Delta U = q + w
```

While internal energy change $\Delta U$ is path-independent, the split between heat $q$ and work $w$ varies with every path!

---

## 2. Cyclic Integrals

The defining mathematical test of a state function is that its cyclic integral around any closed loop is identically zero:

```math
\oint dU = 0, \quad \oint dH = 0
```

However, for path-dependent quantities like work and heat, the cyclic integral represents the net work produced or absorbed by the engine:

```math
\oint dw = w_{\text{net}} \neq 0, \quad \oint dq = q_{\text{net}} \neq 0
```

This non-zero cyclic area in $P$-$V$ indicator diagrams is what allows heat engines to power civilization.

---

## 3. Bridging Path to State via Constraints

To tabulate hidden state functions, we force systems through constrained paths where path functions become exact:

1. **Constant Volume ($dV = 0$)**: Since $dw = -P_{ext} dV = 0$:
   ```math
   q_V = \Delta U
   ```
2. **Constant Pressure ($dP = 0$)**:
   ```math
   q_P = \Delta H = \Delta(U + PV)
   ```

  An ideal gas undergoes a closed thermodynamic cycle returning to its initial state $(P_1, V_1, T_1)$. What is the net change in internal energy $\Delta U$, and does the net work $w_{\text{net}}$ have to be zero?

  <div slot="solution">
    Because internal energy $U$ is a state function:
    ```math
    \Delta U_{\text{cycle}} = \oint dU = 0
    ```
    By the First Law:
    ```math
    \Delta U = q_{\text{net}} + w_{\text{net}} = 0 \implies w_{\text{net}} = -q_{\text{net}}
    ```
    The net work $w_{\text{net}}$ equals the enclosed area on the $P$-$V$ diagram and is generally non-zero.
  </div>
