## Video Production & Animation Engine

Videos and scripts are made from my lecture notes from senior and graduate level university classes. The following tools were used to assist in creating videos

* Animations created with [Manim Community Edition (v0.21+)](https://www.manim.community/)
* Synchronized audio timelines and my voiceovers created with [manim-voiceover (v0.3+)](https://voiceover.manim.community/)
* Avatar lip-sync generated using [Rhubarb Lip Sync (v1.14.0+)](https://github.com/DanielSWolf/rhubarb-lip-sync)
* Voiceover audio enhanced with [Resemble Enhance](https://github.com/resemble-ai/resemble-enhance)
* Coding and image generation assistance from [Antigravity IDE](https://antigravity.google/product/antigravity-ide) and [Gemini Flash (3.8+)](https://gemini.google.com/)
* Vector graphics generated with [Adobe Illustrator (v30+)](https://www.adobe.com/products/illustrator.html) and [Adobe Firefly](https://firefly.adobe.com/)
* Video edited and finalized in [DaVinci Resolve (21)](https://www.blackmagicdesign.com/products/davinciresolve)
* Coding, packaging with [Python 3 (3.10+)](https://www.python.org) and [uv (v0.12+)](https://docs.astral.sh/uv/)

## Web Architecture & Interactive Textbook

The textbook site is designed with the following tools

* Static site generation with [Astro 5](https://astro.build/)
* Documentation tooling and presentation generated with [Starlight](https://starlight.astro.build/)
* Latex formulas rendered with [KaTeX](https://katex.org/)
* Coding assistance from [Antigravity IDE](https://antigravity.google/product/antigravity-ide) and [Gemini Flash (3.8+)](https://gemini.google.com/)
